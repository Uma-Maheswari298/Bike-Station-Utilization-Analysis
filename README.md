# Bike-Station-Utilization-Analysis
Power BI dashboard for bike station analytics and visualization.

## Project Overview
 - This project focus on analyzing bike station dataa using Power BI to monitor station performance, bike availability, and operatinal     status.
-----
## Project Objective
 - Monitoring bike availability across stations.
 - Tracking open and closed station status.
 - To identify highly utilized and underutilized bike stations.
 - To analyze occupancy patterns.
-----
## Tools Used
 - Power BI
 - Power Query
 - DAX
 - Data Modeling
 - Data Visualization

## Data Cleaning & Transformation
 - Removed null values
 - Standardized column names
 - Changed data type
 - Cleaned inconsistent text formatting in station and addresscolumns.
 - Created calculated columns.
 - Created calculated measures.

## Data Modeling
 - Built Calendar Table
 - Created relationship between Fact Table and Calendar Table
 - Used Date-based modeling for trend analysis

## Key KPIs
 - Total Station
 - Total Bike Stand
 - Total Available Bikes
 - Latest Update
 - Closed Station Count
 - Average Stand per Station

## Dashboard Features
 - KPI Cards
 - Interactive Dashboard

## Techniques Used
 - Data Cleaning and Tranformation
 - Data Modeling
 - Calendar Table Creation
 - DAX Measures and Calculations
 - Interactive Slicers
 - KPI and Visual Design
 
## Key Insights
 - Several bike stations show high occupancy levels, indicating heavy usage during peak periods
 - Some stations frequently have low bike availability, which may affect customer convenience
 - Open stations contribute significantly to overall bike availability and operational efficiency
 - Certain stations remain underutilized, showing opportunities for better resource allocation
 - Bike availability and occupied stands vary across different station locations
 - Data analysis revealed patterns in station performance and operational status over time
 - Interactive dashboards helped identify top-performing and low-performing stations quickly
 - Proper data cleaning and modeling improved reporting accuracy and visualization quality
